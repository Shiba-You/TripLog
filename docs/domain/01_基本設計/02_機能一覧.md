# 機能一覧

優先度: ◎=MVP必須 / ○=初期リリース望ましい / △=将来対応

| ID | 機能名 | 概要 | 優先度 |
|---|---|---|---|
| F-001 | 旅行（トリップ）管理 | 旅行の作成・編集・削除。名称・期間・ラベル色を設定 | ◎ |
| F-002 | トラッキングモード | モバイルで開始/一時停止/終了。位置情報を定期取得しトラックとして記録 | ◎ |
| F-003 | 経路の地図可視化 | 取得したトラックを地図上に旅行ごとの色で描画 | ◎ |
| F-004 | バックグラウンド位置取得 | アプリが前面でなくても位置を取得し続ける（iOSバックグラウンド位置） | ◎ |
| F-005 | オフライン蓄積・再送 | 圏外時は点をローカル保存し、復帰時にバッチ送信 | ◎ |
| F-006 | 訪問済みエリア判定（カバレッジ） | トラックポイントから訪問した行政区画を判定 | ◎ |
| F-007 | 訪問エリアの塗りつぶし表示（トロフィー） | 訪問済み区画を地図上で塗りつぶし可視化 | ◎ |
| F-008 | カバレッジ統計 | 訪問区画数・カバー率などの集計表示 | ○ |
| F-009 | GPXインポート | GPXファイルをアップロードしてトラックとして取り込み | ◎ |
| F-010 | トラッキング断絶通知 | 既定5分間位置取得が途絶えたら通知 | ◎ |
| F-011 | 写真の自動同期 | 旅行期間中の撮影写真を取得しR2へアップロード | ○ |
| F-012 | 写真の地点マッピング | EXIFのGPS、無ければ撮影時刻とトラックの突合で地点を決定し地図表示 | ○ |
| F-013 | 写真ギャラリー | 旅行ごとの写真一覧・地図上ピン表示 | ○ |
| F-014 | 家計簿（旅費管理） | 費目・金額・通貨・日時・メモで旅費を記録 | ◎ |
| F-015 | 家計簿の集計 | 旅行ごと・費目ごとの合計・グラフ表示 | ○ |
| F-016 | AIおすすめ経路チャット | 次の目的地・立ち寄り先をClaude APIに相談 | ○ |
| F-017 | Webダッシュボード | 地図・統計・旅行一覧・写真・家計簿の閲覧 | ◎ |
| F-018 | Webアップロード | ブラウザからGPX/画像をアップロード | ◎ |
| F-019 | デバイス登録（プッシュトークン） | APNsトークンの登録・解除（通知の前提） | ◎ |
| F-020 | 設定 | トラッキング間隔・通知・データ管理（エクスポート/削除） | ○ |
| F-021 | データエクスポート | トラック・旅行データのGPX/JSONエクスポート | △ |
| F-022 | 認証・マルチユーザー | サインアップ/ログイン、ユーザーごとのデータ分離（RLS） | △ |
| F-023 | 旅の共有・公開 | 旅行を他者に共有/公開（SNS的機能） | △ |
| F-024 | Android対応 | React NativeベースでのAndroidアプリ提供 | △ |
| F-025 | コメント・日記 | トラック/写真に複数コメントを残し時系列で振り返り。旅行中の日記用途 | ○ |
| F-026 | マップ画面の写真ピン表示 | メイン地図に撮影写真を撮影地点のピンとして重畳表示 | ○ |

## MVPの範囲

最初のリリース（自分専用・自宅サーバ運用）に含める機能:

**F-001, F-002, F-003, F-004, F-005, F-006, F-007, F-009, F-010, F-014, F-017, F-018, F-019**

これにより「旅行を作る → トラッキングして経路を地図に残す → 訪問エリアが埋まる → 断絶時は通知 → GPXも取り込める → 旅費を記録 → Webで振り返る」という中心体験が一通り成立する。

写真同期（F-011〜F-013）・カバレッジ統計（F-008）・家計簿集計（F-015）・AIチャット（F-016）・コメント/日記（F-025）・マップ写真ピン（F-026）・設定の充実（F-020）は初期リリース直後の優先実装（○）とし、認証/公開/Android（F-022〜F-024）は将来対応（△）とする。なお F-025 のうちトラックへのコメントは写真機能に依存しないため、希望に応じてMVPへ前倒ししやすい。
