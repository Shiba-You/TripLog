# TripLog 設計ドキュメント

## このサービスについて

TripLog は、旅行好きの個人が「自分の旅の軌跡を記録・可視化・コレクションする」ための個人向け旅行ログサービスである。旅行中にモバイルアプリで位置情報を自動トラッキングして経路を地図に描き、訪れた土地が地図上で塗りつぶされていく様子を「トロフィー」のように楽しめる。あわせて、撮影写真の地点マッピング、旅行ごとのラベリング、旅費の家計簿、AIによるおすすめ経路チャットを備える。OSSの類似サービス Adventure Log を参考にしつつ、まずは作者自身の利用を起点とし、将来的にOSS化・App Store公開を目指す。

## ドキュメント一覧（推奨の読む順序）

1. `01_要件定義書.md` — 何を作るか（背景・スコープ・機能/非機能要件）
2. `02_機能一覧.md` — 機能とその優先度（MVP範囲）
3. `03_アーキテクチャと技術選定.md` — どう作るか（全体構成と技術選定理由）
4. `04_データモデル.md` — 扱うデータ（エンティティ定義・ER図）
5. `05_画面設計.md` — 画面と遷移（Figma向け設計仕様）
6. `06_API設計.md` — サーバーとのやり取り（OpenAPI定義）
7. `07_開発引き継ぎ.md` — 実装に着手するための情報（構成・順序・未確定事項）

あわせて `openapi.yaml`（`06_API設計.md` と同内容の機械可読版）を同梱する。

## 想定プラットフォーム

- **iOSネイティブアプリ**: React Native（位置トラッキング・写真同期・通知のコアを担う）
- **PCブラウザ（Windows / Mac）**: ダッシュボード中心（閲覧・振り返り＋GPX/画像アップロード）

## 主要な技術選定（要約）

| レイヤー | 採用 |
|---|---|
| モバイル | React Native（Expo + Dev Build） |
| Web | React（ダッシュボード） |
| 地図レンダラ | MapLibre GL（Web: GL JS / RN: maplibre-react-native） |
| 地図タイル | Protomaps PMTiles（Cloudflare R2に自前ホスト）＋ 国内は地理院タイル併用可 |
| バックエンド | Java + Spring Boot |
| DB | PostgreSQL 16 + PostGIS（自宅サーバ自前運用 → 将来Supabase/AWS） |
| 写真ストレージ | Cloudflare R2（S3互換） |
| AIチャット | Claude（Anthropic）API |
| 認証 | なし（単一ユーザー）。将来マルチユーザー化を見据えて設計 |
| インフラ | 自宅サーバをAPIサーバとして開始 → 形になり次第AWSへ移行 |
