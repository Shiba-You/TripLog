## 状態

通常 / 空 / 追加・編集モーダル

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 費用一覧を取得 | `GET /api/trips/{tripId}/expenses` | `SELECT id, category, amount, currency, description, spent_at FROM expenses WHERE trip_id = $1 ORDER BY spent_at DESC;` |
| 2 | 画面表示 | 費目別集計・合計を取得 | `GET /api/trips/{tripId}/expenses/summary` | `SELECT category, SUM(amount) AS amount FROM expenses WHERE trip_id = $1 GROUP BY category ORDER BY amount DESC;`<br>`SELECT currency, SUM(amount) AS total FROM expenses WHERE trip_id = $1 GROUP BY currency;` |
| 3 | 追加モーダルの送信 | 費用を新規登録 | `POST /api/trips/{tripId}/expenses` | `INSERT INTO expenses (id, trip_id, user_id, category, amount, currency, description, spent_at) VALUES (gen_random_uuid(), $1, $2, $3, $4, $5, $6, $7) RETURNING id, category, amount, currency, spent_at;` |
| 4 | 費用リストの項目タップ→編集モーダル送信 | 費用を更新 | `PATCH /api/expenses/{expenseId}` | `UPDATE expenses SET category=$1, amount=$2, currency=$3, description=$4, spent_at=$5 WHERE id=$6 RETURNING *;` |
| 5 | 費用リストの削除操作（スワイプ削除等、確認ダイアログ後） | 費用を削除 | `DELETE /api/expenses/{expenseId}` | `DELETE FROM expenses WHERE id = $1;` |
| 6 | タブバーのタップ | S-001／S-003／S-009へ遷移 | - | - |

## 補足

- 本画面はS-004（旅行詳細）からの遷移では対象旅行が確定しているが、下部タブから直接遷移した場合は対象旅行が未確定となる。その場合は旅行選択（プルダウン等）を上部に表示し、選択後に上記処理を実行する。
