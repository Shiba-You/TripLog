## 目的

帰宅後にPCの大画面で旅を俯瞰し、コレクションの達成感を味わう。（`docs/01_基本設計/05_画面設計.md` W-001参照）

## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 統計サイドバー（左） | パネル | 下記1-1〜1-3 | - | - |
| 1-1 | ├ 訪問国／都道府県／市区町村数 | 数値表示×3 | `region_type`別の訪問済み件数 | `visited_regions` × `regions.region_type` | 該当`region_type`の`regions`未投入時は「-」表示 |
| 1-2 | ├ カバー率 | パーセント表示＋プログレスバー | 訪問済み/総数 | `/api/coverage` の `stats.coverageRate` | `totalCount`=0の場合「集計不可」表示 |
| 1-3 | ├ トロフィー一覧 | リスト | 区画名＋初訪問日 | `visited_regions.region_id`→`regions.name` / `visited_regions.first_visited_at` | 0件は「まだ訪問済みエリアがありません」 |
| 2 | 中央地図 | 地図（全旅行俯瞰） | 経路・訪問エリア塗りつぶし・写真ピン | `tracks`/`track_points`/`visited_regions`/`regions`/`photos` | S-001と同様の欠損時挙動 |
| 3 | 上部旅行フィルタ | チップ／マルチセレクト | 旅行ごとの表示ON/OFF | `trips.id` / `trips.name` / `trips.color` | `trips`0件時は非表示 |

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 旅行一覧（フィルタ用）を取得 | `GET /api/trips` | `SELECT id, name, color FROM trips WHERE user_id = $1 ORDER BY started_on DESC NULLS LAST;` |
| 2 | 画面表示 | 訪問済みエリア（塗りつぶし用GeoJSON）を`region_type`別に取得し統計サイドバーと地図に反映 | `GET /api/coverage?regionType=country`（他 `prefecture` / `city` も同様に呼び出し） | `SELECT region_type, COUNT(*) AS visited_count FROM visited_regions vr JOIN regions r ON r.id = vr.region_id WHERE vr.user_id = $1 GROUP BY region_type;`<br>`SELECT region_type, COUNT(*) AS total_count FROM regions GROUP BY region_type;` |
| 3 | 画面表示 | トロフィー一覧（直近訪問順）を取得 | `GET /api/coverage` のレスポンスから整形、または個別集計 | `SELECT r.name, r.region_type, vr.first_visited_at FROM visited_regions vr JOIN regions r ON r.id = vr.region_id WHERE vr.user_id = $1 ORDER BY vr.first_visited_at DESC;` |
| 4 | 画面表示（フィルタ対象の旅行ごと） | 経路・写真ピンを取得し地図へ描画 | `GET /api/trips/{tripId}/tracks` → `GET /api/tracks/{trackId}/points`, `GET /api/photos?bbox=...` | S-001の処理No.3・4と同一 |
| 5 | 旅行フィルタの操作 | クライアント側で表示対象を絞り込み | - | - |
| 6 | 地図上の旅行クリック／ナビゲーション | W-002（旅行ビュー）へ遷移 | - | - |
