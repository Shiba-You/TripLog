## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 旅行名 | テキスト（インライン編集可） | 1〜50文字必須 | `trips.name` | - |
| 2 | 期間 | 日付表示／編集 | 終了日は開始日以降 | `trips.started_on` / `trips.ended_on` | いずれかNULLは「期間未設定」 |
| 3 | ラベル色編集 | カラーパレット選択（7色） | - | `trips.color` | - |
| 4 | 地図（この旅行の経路） | 地図（読み取り専用） | 当該旅行の全トラックを重畳表示 | `tracks.trip_id` → `track_points.geom` | トラック0件時は地図のみ（オーバーレイ無し） |
| 5 | トラック一覧セクション | リスト | 1件=1トラック | - | - |
| 5-1 | ├ 種別バッジ | バッジ | 「ライブ記録」／「GPXインポート」 | `tracks.source` | - |
| 5-2 | ├ 状態 | テキスト | 記録中／一時停止／完了 | `tracks.status` | - |
| 5-3 | ├ 期間・距離・点数 | テキスト | `started_at`〜`ended_at`、距離、`track_points`件数 | `tracks.started_at` / `tracks.ended_at` / `track_points` | `ended_at`がNULL（記録中）は「記録中」表示 |
| 5-4 | ├ コメント（日記）スレッド | リスト（時系列） | 投稿者・本文・投稿日時 | `comments`（`target_type='track'`） | 0件は「まだコメントがありません」 |
| 5-5 | ├ コメント追記欄 | テキストエリア＋送信ボタン | 1〜1000文字、空文字送信不可 | `comments.body` | - |
| 6 | 写真セクション | サムネ横並び＋「すべて見る」 | 先頭数件のサムネ表示 | `photos.thumbnail_key` | 0件は「まだ写真がありません」＋セクション簡略表示 |
| 7 | 家計簿サマリセクション | 合計金額＋費目別内訳（簡易） | 「すべて見る」でS-006へ | `expenses`集計 | 0件は「¥0 / 記録なし」 |
| 8 | AIに相談ボタン | ボタン | タップでS-007（当該`tripId`のセッション作成）へ | - | - |
| 9 | GPX追加ボタン | ボタン | タップでS-008（当該`tripId`指定）へ | - | - |

## 状態

通常 / 写真同期中 / コメント投稿中 / 空（トラック0件）

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 旅行本体を取得 | `GET /api/trips/{tripId}` | `SELECT id, name, description, color, started_on, ended_on FROM trips WHERE id = $1 AND user_id = $2;` |
| 2 | 画面表示 | トラック一覧を取得 | `GET /api/trips/{tripId}/tracks` | `SELECT id, source, status, started_at, ended_at, last_point_at, (SELECT COUNT(*) FROM track_points tp WHERE tp.track_id = tracks.id) AS point_count FROM tracks WHERE trip_id = $1 ORDER BY started_at ASC NULLS LAST;` |
| 3 | 画面表示（各トラックごと） | 経路点を取得し地図に描画 | `GET /api/tracks/{trackId}/points` | `SELECT geom, recorded_at FROM track_points WHERE track_id = $1 ORDER BY recorded_at ASC;` |
| 4 | 画面表示（各トラックごと） | コメント（日記）一覧を取得 | `GET /api/tracks/{trackId}/comments` | `SELECT id, body, created_at, updated_at FROM comments WHERE target_type = 'track' AND target_id = $1 ORDER BY created_at ASC;` |
| 5 | 画面表示 | 写真サムネ・家計簿サマリを取得 | `GET /api/trips/{tripId}/photos`, `GET /api/trips/{tripId}/expenses/summary` | `SELECT id, thumbnail_key, taken_at FROM photos WHERE trip_id = $1 ORDER BY taken_at ASC NULLS LAST LIMIT 6;`<br>`SELECT category, SUM(amount) AS amount FROM expenses WHERE trip_id = $1 GROUP BY category;` |
| 6 | 旅行名／期間／色の編集保存 | 旅行情報を更新 | `PATCH /api/trips/{tripId}` | `UPDATE trips SET name=$1, description=$2, color=$3, started_on=$4, ended_on=$5, updated_at=now() WHERE id=$6 RETURNING *;` |
| 7 | コメント追記欄で送信 | トラックへコメントを追加 | `POST /api/tracks/{trackId}/comments` | `INSERT INTO comments (id, user_id, target_type, target_id, body) VALUES (gen_random_uuid(), $1, 'track', $2, $3) RETURNING id, body, created_at;` |
| 8 | コメントの編集 | コメント本文を更新 | `PATCH /api/comments/{commentId}` | `UPDATE comments SET body=$1, updated_at=now() WHERE id=$2 AND user_id=$3 RETURNING id, body, updated_at;` |
| 9 | コメントの削除（確認ダイアログ後） | コメントを削除 | `DELETE /api/comments/{commentId}` | `DELETE FROM comments WHERE id = $1 AND user_id = $2;` |
| 10 | 写真セクション「すべて見る」／サムネタップ | S-005へ遷移 | - | - |
| 11 | 家計簿サマリ「すべて見る」 | S-006へ遷移 | - | - |
| 12 | AIに相談ボタンのタップ | AIチャットセッションを作成しS-007へ遷移 | `POST /api/ai/chat/sessions` `{tripId}` | `INSERT INTO ai_chat_sessions (id, user_id, trip_id, title) VALUES (gen_random_uuid(), $1, $2, $3) RETURNING id, trip_id, created_at;` |
| 13 | GPX追加ボタンのタップ | S-008へ遷移（取込先旅行として当該`tripId`を初期選択） | - | - |
