## 目的

旅費を費目別・期間別に集計し、俯瞰的に把握する（`docs/01_基本設計/05_画面設計.md` W-004参照）。

## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 対象旅行選択 | プルダウン | 旅行未選択時は全旅行横断集計（将来拡張。MVPでは旅行単位が基本） | `trips.id` / `trips.name` | - |
| 2 | 費目別集計グラフ | チャート | `category`別 | `expenses.category` / `expenses.amount` | 0件時はグラフ非表示＋空メッセージ |
| 3 | 期間別集計グラフ | チャート（月次等） | `spent_at`を期間でグルーピング（クライアント側集計） | `expenses.spent_at` | - |
| 4 | 費用一覧テーブル | テーブル（ソート可） | 列: 費目・金額・通貨・メモ・支出日時 | `expenses.*` | `description`NULLはハイフン表示 |
| 5 | CSV出力ボタン | ボタン | F-021（優先度△・将来対応）につき本MVPでは非活性（準備中）表示 | - | - |
| 6 | 追加・編集モーダル | モーダルフォーム | S-006と同一項目・同一バリデーション | `expenses.*` | - |

## 状態

通常 / 空 / 追加・編集モーダル

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示（対象旅行選択後） | 費用一覧・集計を取得 | `GET /api/trips/{tripId}/expenses`, `GET /api/trips/{tripId}/expenses/summary` | S-006の処理No.1・2と同一 |
| 2 | 期間別集計の表示 | 取得済み費用一覧をクライアント側で月次集計 | - | `SELECT date_trunc('month', spent_at) AS month, SUM(amount) AS amount FROM expenses WHERE trip_id = $1 GROUP BY month ORDER BY month;`（相当。実装はクライアント側集計でも可） |
| 3 | テーブルのソート操作 | クライアント側で並び替え | - | - |
| 4 | 追加・編集モーダルの送信 | 費用の登録／更新 | `POST /api/trips/{tripId}/expenses` / `PATCH /api/expenses/{expenseId}` | S-006の処理No.3・4と同一 |
| 5 | 削除操作（確認ダイアログ後） | 費用を削除 | `DELETE /api/expenses/{expenseId}` | `DELETE FROM expenses WHERE id = $1;` |
| 6 | CSV出力ボタンのタップ | 未実装（F-021将来対応のためクリック不可、または「準備中」トースト表示） | - | - |
