| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 新規作成ボタン | ボタン（上部固定） | タップで作成モーダル表示 | - | - |
| 2 | 検索欄 | テキスト入力 | 旅行名の部分一致でクライアント側フィルタ | `trips.name` | - |
| 3 | 旅行カード（リスト） | カードリスト | 1件=1旅行 | - | - |
| 3-1 | ├ 旅行名 | テキスト | - | `trips.name` | - |
| 3-2 | ├ 期間 | テキスト | `started_on`〜`ended_on` | `trips.started_on` / `trips.ended_on` | いずれかNULLの場合「期間未設定」表示 |

| 3-4 | ├ サムネイル | 画像 | 写真優先、無ければ経路プレビュー | `photos.thumbnail_key`（同旅行の最初の1枚）／無ければ `track_points.geom` から生成した経路サムネ | どちらも無ければプレースホルダー画像 |
| 3-5 | ├ 訪問区画数 | テキスト（件） | 当該旅行が初訪問となった区画数 | `visited_regions.first_trip_id = trips.id` の件数 | 0件はそのまま「0」を表示（欠損ではなく実値） |
| 4 | 空状態 | イラスト＋テキスト＋CTA | 「旅行がありません。最初の旅行を作りましょう」 | `trips` 件数=0で表示判定 | - |
| 5 | ローディング状態 | スケルトン表示 | 初回データ取得中 | - | - |
| 6 | 作成モーダル | モーダルフォーム | 下記6-1〜6-4 | - | - |
| 6-1 | ├ 名称 | テキスト入力（必須） | 1〜50文字 | `trips.name` | - |
| 6-2 | ├ 期間 | 日付入力×2（任意） | 終了日は開始日以降であること | `trips.started_on` / `trips.ended_on` | - |
| 6-3 | ├ ラベル色 | カラーパレット選択（必須） | 7色（ティール/オレンジ/ブルー/パープル/グリーン/レッド/イエロー）から1つ選択 | `trips.color` | - |
| 6-4 | ├ メモ | テキストエリア（任意） | 1000文字以内 | `trips.description` | - |
| 7 | 下部タブバー | タブ（4項目） | 現在タブ=旅行をハイライト | - | - |

## 状態

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 旅行一覧（訪問区画数を含む）を取得 | `GET /api/trips` | `SELECT t.id, t.name, t.description, t.color, t.started_on, t.ended_on, (SELECT COUNT(*) FROM visited_regions vr WHERE vr.first_trip_id = t.id) AS visited_region_count FROM trips t WHERE t.user_id = $1 ORDER BY t.started_on DESC NULLS LAST, t.created_at DESC;` |
| 2 | 検索欄への入力 | クライアント側で `name` の部分一致フィルタ（現行APIに検索クエリパラメータは無いため） | - | - |
| 3 | カードのタップ | S-004（旅行詳細）へ遷移（`tripId`を渡す） | - | - |
| 4 | 新規作成ボタンのタップ | 作成モーダルを表示 | - | - |
| 5 | 作成モーダルの送信 | 旅行を新規作成し、成功したらモーダルを閉じ一覧を再取得 | `POST /api/trips` | `INSERT INTO trips (id, user_id, name, description, color, started_on, ended_on) VALUES (gen_random_uuid(), $1, $2, $3, $4, $5, $6) RETURNING id, name, color, started_on, ended_on, created_at;` |
| 6 | 作成モーダルのバリデーションエラー | `name`未入力・`color`未選択時はサーバ`400`または送信前のクライアントバリデーションでエラーメッセージ表示 | - | - |
| 7 | タブバーのタップ | S-001／S-006／S-009へ遷移 | - | - |
