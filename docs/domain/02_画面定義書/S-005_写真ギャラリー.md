## 目的

撮影地点と紐づいた写真の閲覧。（`docs/01_基本設計/05_画面設計.md` S-005参照）

## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 表示切替トグル | セグメントコントロール | 「グリッド」／「地図」 | - | - |
| 2 | サムネイル格子（グリッド表示時） | グリッド | タップで詳細へ | `photos.thumbnail_key` | `thumbnail_key`がNULLの場合は原本(`r2_object_key`)から縮小、両方の取得に失敗した場合は破損画像プレースホルダー |
| 3 | 写真ピン（地図表示時） | 地図マーカー | 撮影地点にピン表示 | `photos.geom` | - |
| 4 | 位置不明の写真グループ | 折りたたみリスト（地図表示時） | 「地図外」として別リスト表示 | `photos.location_source = 'unknown'`（`geom IS NULL`） | - |
| 5 | 空状態 | イラスト＋テキスト | 「まだ写真がありません」 | `photos` 件数=0 | - |
| 6 | 写真詳細（拡大表示） | モーダル／画面 | 下記6-1〜6-4 | - | - |
| 6-1 | ├ 拡大画像 | 画像 | 原本表示 | `photos.r2_object_key` | - |
| 6-2 | ├ 撮影地点 | テキスト（緯度経度） | 地名逆引きは将来対応 | `photos.geom` | `geom`NULLは「撮影地点不明」 |
| 6-3 | ├ 撮影時刻 | テキスト | - | `photos.taken_at` | NULLは「撮影時刻不明」 |
| 6-4 | ├ 時系列コメント（日記）一覧＋追記欄 | リスト＋テキストエリア | 1〜1000文字、空文字送信不可 | `comments`（`target_type='photo'`） | 0件は「まだコメントがありません」 |

## 状態

通常 / 位置不明の写真（地図外グループ表示） / コメント投稿中 / 空

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 当該旅行の写真一覧を取得 | `GET /api/trips/{tripId}/photos` | `SELECT id, ST_X(geom::geometry) AS lng, ST_Y(geom::geometry) AS lat, location_source, taken_at, r2_object_key, thumbnail_key, width, height FROM photos WHERE trip_id = $1 ORDER BY taken_at ASC NULLS LAST;` |
| 2 | 表示切替トグルの操作 | クライアント内表示切替のみ（再取得なし） | - | - |
| 3 | 写真のタップ | 詳細表示＋当該写真のコメント一覧取得 | `GET /api/photos/{photoId}/comments` | `SELECT id, body, created_at, updated_at FROM comments WHERE target_type = 'photo' AND target_id = $1 ORDER BY created_at ASC;` |
| 4 | コメント追記欄で送信 | 写真へコメントを追加 | `POST /api/photos/{photoId}/comments` | `INSERT INTO comments (id, user_id, target_type, target_id, body) VALUES (gen_random_uuid(), $1, 'photo', $2, $3) RETURNING id, body, created_at;` |
| 5 | コメントの編集 | コメント本文を更新 | `PATCH /api/comments/{commentId}` | `UPDATE comments SET body=$1, updated_at=now() WHERE id=$2 AND user_id=$3 RETURNING id, body, updated_at;` |
| 6 | コメントの削除（確認ダイアログ後） | コメントを削除 | `DELETE /api/comments/{commentId}` | `DELETE FROM comments WHERE id = $1 AND user_id = $2;` |
