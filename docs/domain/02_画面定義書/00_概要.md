# 画面定義書 概要

## 位置づけ

本ディレクトリは `docs/domain/01_基本設計/05_画面設計.md`（画面設計・Figma向け仕様）を基に、各画面の詳細定義（画面イメージ・画面項目・処理・クエリ）を1画面1ファイルで記載する。

- 情報設計・状態・遷移の一次情報は `docs/domain/01_基本設計/05_画面設計.md`
- データモデルの一次情報は `docs/domain/01_基本設計/04_データモデル.md`
- API仕様の一次情報は `docs/domain/01_基本設計/06_API設計.md`（本書のSQLはこのAPI裏側の相当処理を示す）

## 共通前提

- MVPは単一ユーザー運用。全クエリの `user_id` はシードされた唯一のユーザーIDを内部的に使用する（APIは認証なし、将来 `X-API-Key` を追加）。
- DBは PostgreSQL 16 + PostGIS。時刻は `timestamptz`（UTC保存）。
- 本書中のSQLは実装（ORM/クエリビルダ等）を拘束するものではなく、API裏側で発生する処理の相当内容を示す参考記載。プレースホルダは `$1, $2...` 表記。
- Figmaファイル（ベース）: https://www.figma.com/design/JeilqxYLk7NZeWFPo5wh9q/Untitled
  各画面の詳細URL（node-id付き）は各画面定義書に記載。
- **Figmaプロトタイプは14画面中6画面（S-001〜S-006）まで作成完了、Figma MCPのツール呼び出し上限により中断中。進捗・再開手順は [docs/works/figma_prototype_progress.md](../../works/figma_prototype_progress.md) を参照。**
