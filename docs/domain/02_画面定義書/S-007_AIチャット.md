## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | メッセージ一覧（吹き出し） | チャットリスト | `role=user`は右寄せ、`role=assistant`は左寄せ | `ai_chat_messages.role` / `ai_chat_messages.content` / `ai_chat_messages.created_at` | セッション新規作成直後（0件）は「何を相談しますか？」のプレースホルダー表示 |
| 2 | 入力欄 | テキストエリア | 1〜2000文字、空文字送信不可、送信中はdisabled | - | - |
| 3 | 送信ボタン | ボタン | 入力欄が空／送信中は非活性 | - | - |
| 4 | ストリーミング中インジケータ | ドットアニメーション | assistant応答受信中に表示 | - | - |
| 5 | エラー表示＋再試行ボタン | バナー＋ボタン | 送信失敗時に表示 | - | - |
| 6 | 提案地点の地図確認リンク | インラインボタン（吹き出し内） | タップでS-001またはS-004へ遷移 | - | 応答文からの座標抽出は将来対応。MVPでは付与されない場合あり |
| 7 | コンテキスト表示（任意） | 小テキスト | 現在の旅行名／現在地の付与有無を表示 | `trips.name`（`ai_chat_sessions.trip_id`経由） | 未付与時は非表示 |

## 状態

通常 / 応答ストリーミング中 / エラー（再試行）

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示（初回遷移時） | チャットセッションを作成（S-004経由なら`tripId`付与） | `POST /api/ai/chat/sessions` | `INSERT INTO ai_chat_sessions (id, user_id, trip_id, title) VALUES (gen_random_uuid(), $1, $2, $3) RETURNING id, trip_id, created_at;` |
| 2 | 送信ボタンのタップ／Enter送信 | ユーザーメッセージを保存し、Claude APIへ中継。応答をSSEで逐次受信し画面に描画、完了後にassistantメッセージを保存 | `POST /api/ai/chat/sessions/{sessionId}/messages` | `INSERT INTO ai_chat_messages (id, session_id, role, content) VALUES (gen_random_uuid(), $1, 'user', $2) RETURNING id, created_at;`（送信直後、サーバ側）<br>`INSERT INTO ai_chat_messages (id, session_id, role, content) VALUES (gen_random_uuid(), $1, 'assistant', $2);`（ストリーミング完了後、サーバ側） |
| 3 | 送信失敗（ネットワークエラー等） | エラーバナー表示、再試行ボタンで直前のリクエストを再送 | `POST /api/ai/chat/sessions/{sessionId}/messages`（再送） | 上記No.2と同一 |
| 4 | 提案地点リンクのタップ | S-001またはS-004へ遷移 | - | - |

## 補足

- 既存セッションの履歴一覧取得API（例: `GET /api/ai/chat/sessions/{sessionId}/messages`）は現行の`06_API設計.md`に未定義。画面再訪時に履歴を復元する場合はクライアント側の一時保持、またはAPI拡張が必要。参考の相当SQLは以下。

```sql
SELECT id, role, content, created_at
FROM ai_chat_messages
WHERE session_id = $1
ORDER BY created_at ASC;
```
