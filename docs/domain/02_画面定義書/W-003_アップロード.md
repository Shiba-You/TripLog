## 状態

待機 / アップロード中 / 完了 / 一部失敗（再試行）

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 取込先旅行の選択肢を取得 | `GET /api/trips` | `SELECT id, name, color FROM trips WHERE user_id = $1 ORDER BY started_on DESC NULLS LAST;` |
| 2 | 「新規作成」選択で確定 | 旅行を新規作成 | `POST /api/trips` | `INSERT INTO trips (id, user_id, name, color) VALUES (gen_random_uuid(), $1, $2, $3) RETURNING id, name, color;` |
| 3 | GPXファイルのアップロード開始 | ファイルをサーバへ送信し、トラック・トラックポイントとして取り込む | `POST /api/trips/{tripId}/import/gpx`（multipart/form-data） | S-008の処理No.4と同一 |
| 4 | 画像ファイルのアップロード開始 | 署名付きURLを発行→R2へPUT→メタデータ登録（EXIF GPSがあればそのまま、無ければ撮影時刻とトラックの突合） | `POST /api/photos/presign` → R2へ`PUT` → `POST /api/trips/{tripId}/photos` | `INSERT INTO photos (id, trip_id, user_id, geom, location_source, taken_at, r2_object_key, width, height, exif) VALUES (gen_random_uuid(), $1, $2, CASE WHEN $3::float IS NOT NULL THEN ST_SetSRID(ST_MakePoint($3,$4),4326)::geography ELSE NULL END, CASE WHEN $3::float IS NOT NULL THEN 'exif' ELSE 'unknown' END, $5, $6, $7, $8, $9) RETURNING id, location_source;`<br>（EXIF GPS無しの場合の突合）`SELECT id, geom FROM track_points WHERE track_id IN (SELECT id FROM tracks WHERE trip_id = $1) ORDER BY abs(extract(epoch from (recorded_at - $2::timestamptz))) LIMIT 1;` |
| 5 | 各ファイルのアップロード進捗 | 進捗バーを更新（クライアント側のXHR/Fetch進捗イベント） | - | - |
| 6 | 失敗ファイルの再試行ボタン | 当該ファイルのみ再送 | 上記No.3またはNo.4と同一 | - |
| 7 | 全件完了 | 完了トースト表示、W-002（該当旅行）への遷移導線を表示 | - | - |
