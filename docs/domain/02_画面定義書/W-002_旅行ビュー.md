## 目的

旅行一覧から任意の1旅行を選び、経路・写真・家計簿をまとめて閲覧する（モバイルのS-003＋S-004相当をWebの広い画面で統合したビュー）。（`docs/01_基本設計/05_画面設計.md` W-002参照）

## 画面項目

| No | 項目 | 種別 | 内容・バリデーション | 参照元（テーブル.カラム） | 欠損値・空値時の表示 |
|---|---|---|---|---|---|
| 1 | 旅行一覧（左ペイン） | リスト | 旅行名・期間・ラベル色 | `trips.name` / `trips.started_on` / `trips.ended_on` / `trips.color` | `started_on`/`ended_on`いずれかNULLは「期間未設定」。`trips`0件は「旅行がありません」＋作成導線 |
| 2 | 旅行詳細（右ペイン） | パネル | 選択中旅行の詳細 | - | 未選択時は「旅行を選択してください」プレースホルダー |
| 2-1 | ├ 旅行情報（名称・期間・色編集） | フォーム | S-004と同様のバリデーション | `trips.*` | - |
| 2-2 | ├ 経路地図 | 地図 | 当該旅行の全トラック重畳表示 | `tracks` / `track_points` | トラック0件は地図のみ |
| 2-3 | ├ 写真一覧 | サムネグリッド | - | `photos.thumbnail_key` | 0件は「まだ写真がありません」 |
| 2-4 | ├ 家計簿サマリ | 集計表示＋「詳細を見る」 | 「詳細を見る」でW-004へ | `expenses`集計 | 0件は「¥0 / 記録なし」 |
| 3 | 新規作成ボタン | ボタン | 作成モーダル表示 | - | - |

## 処理

| No | トリガー | 処理内容 | 呼び出しAPI | クエリ（相当のSQL） |
|---|---|---|---|---|
| 1 | 画面表示 | 旅行一覧を取得 | `GET /api/trips` | `SELECT id, name, description, color, started_on, ended_on FROM trips WHERE user_id = $1 ORDER BY started_on DESC NULLS LAST, created_at DESC;` |
| 2 | 旅行選択（左ペインのクリック） | 選択旅行の詳細・トラック・写真・家計簿サマリを取得 | `GET /api/trips/{tripId}`, `GET /api/trips/{tripId}/tracks`, `GET /api/tracks/{trackId}/points`, `GET /api/trips/{tripId}/photos`, `GET /api/trips/{tripId}/expenses/summary` | S-004の処理No.1〜5と同一 |
| 3 | 旅行情報の編集保存 | 旅行情報を更新 | `PATCH /api/trips/{tripId}` | `UPDATE trips SET name=$1, description=$2, color=$3, started_on=$4, ended_on=$5, updated_at=now() WHERE id=$6 RETURNING *;` |
| 4 | 新規作成ボタン→モーダル送信 | 旅行を新規作成 | `POST /api/trips` | `INSERT INTO trips (id, user_id, name, description, color, started_on, ended_on) VALUES (gen_random_uuid(), $1, $2, $3, $4, $5, $6) RETURNING id, name, color, started_on, ended_on, created_at;` |
| 5 | 家計簿サマリ「詳細を見る」 | W-004（家計簿ビュー、当該`tripId`指定）へ遷移 | - | - |
